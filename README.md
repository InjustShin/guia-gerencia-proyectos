# Guía Interactiva — Gerencia de Proyectos en Computación (Temas 1, 2 y 3)

Aplicación web autocontenida (un único archivo `index.html` con CSS y JavaScript integrados, modo claro/oscuro y diseño responsive para PC y móvil) diseñada para estudiar y practicar los 3 temas del examen tomando como eje el caso práctico **«EduConecta 360»** y la **Guía del PMBOK® 6.ª Edición**.

## Módulos incluidos

### Tema 1 · Control de Adquisiciones y Proveedores (`#tema-1`)
- **Tipos de contratos (PMBOK® §12.1.1.6)** y espectro interactivo de riesgo de costo (*Precio Fijo*, *Tiempo y Materiales T&M*, *Costos Reembolsables*).
- **5 herramientas de Controlar las Adquisiciones (§12.3)** y plantilla de respuesta de examen (*Acción + Sustento + Evidencia*).
- **Caso resuelto «EduConecta 360» (Pregunta 1)**: radiografía de la factura de 360 h de QualityLab y control semanal del techo de 1,200 h.
- **Simulador de auditoría de factura T&M y techo NTE** + **Quiz de 5 escenarios**.

### Tema 2 · Gestión de Conflictos y Modelo de Tuckman (`#tema-2`)
- **Modelo de Tuckman (1965 / 1977)** alineado con PMBOK® §9.4, curva interactiva multicapa y simulador de no linealidad.
- **Liderazgo Situacional (Hersey–Blanchard)** y tabla maestra comparativa.
- **Gestión de Conflictos (PMBOK® §9.5)**: 5 técnicas de resolución + **Caso «EduConecta 360» (Pregunta 2)**.
- **Caso de software (*Squad Nova*)**, autodiagnóstico de 8 ítems, quiz PMP/PMBOK y comparación con el Equilibrio Puntuado de Gersick.

### Tema 3 · Método del Valor Ganado — EVM (`#tema-3`)
- **4 variables base (`PV`, `EV`, `AC`, `BAC`)** con pregunta filtro y atajo por porcentajes.
- **Trucos mnemotécnicos** para las 6 fórmulas (`CV`, `SV`, `CPI`, `SPI`, `EAC`, `VAC`), semáforo rápido y **alerta de redondeo del CPI**.
- **Caso resuelto «EduConecta 360» (Pregunta 3)** con sustitución exacta y pitch ejecutivo modelo de 3 líneas.
- **Simulador / Calculadora EVM en vivo** con sliders, gráficos SVG dinámicos (*Barras* + *Cuadrantes SPI vs. CPI*) y generador automático de pitch.
- **Modo Práctica de examen**: ejercicios numéricos aleatorios y con porcentajes con corrector inteligente.
