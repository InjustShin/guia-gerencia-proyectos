# Guía Interactiva GPC — Tema 2 (Tuckman y Conflictos) & Tema 3 (Valor Ganado EVM)

Aplicación web autocontenida (un único archivo `index.html` con CSS y JavaScript integrados, modo claro/oscuro y diseño responsive para PC y móvil) para estudiar y practicar los temas clave de **Gerencia de Proyectos en Computación**.

## Módulos incluidos

### Tema 2 · Gestión de conflictos y Modelo de Tuckman (`#tema-2`)
- **Modelo de Tuckman (1965 / 1977)** alineado con PMBOK® 6.ª Edición (§9.4): los dos planos (*Interpersonal* y *Tarea*) y curva interactiva multicapa.
- **Simulador de no linealidad**: retrocesos y atajos ante cambios de alcance, personal o equipos veteranos.
- **Liderazgo Situacional (Hersey–Blanchard)** y tabla maestra comparativa.
- **Gestión de Conflictos (PMBOK® §9.5)** con las 5 técnicas y resolución de la Pregunta 2 del caso **«EduConecta 360»**.
- **Caso de software (*Squad Nova*)**, autodiagnóstico de 8 ítems, quiz PMP/PMBOK y comparación con el Equilibrio Puntuado de Gersick.

### Tema 3 · Método del Valor Ganado — EVM (`#tema-3`)
- **4 variables base (`PV`, `EV`, `AC`, `BAC`)** explicadas con pregunta filtro de examen y atajo por porcentajes.
- **Guía visual y trucos mnemotécnicos** para las 6 fórmulas (`CV`, `SV`, `CPI`, `SPI`, `EAC`, `VAC`), semáforo rápido y **alerta de redondeo del CPI**.
- **Caso resuelto paso a paso «EduConecta 360»** con sustitución exacta y pitch ejecutivo modelo de 3 líneas.
- **Simulador / Calculadora EVM en vivo** con sliders, escenarios precargados, gráfico de barras dinámicas, mapa de cuadrantes `SPI vs. CPI` y generador automático de pitch ejecutivo.
- **Modo Práctica de examen**: generador de ejercicios numéricos (estándar, con porcentajes y EduConecta 360) con corrector inteligente que detecta inversiones de fórmula y redondeo prematuro del `CPI`.
