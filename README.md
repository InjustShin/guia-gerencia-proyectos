# El Modelo de Tuckman — Guía Interactiva

Guía web interactiva y autocontenida sobre **la escalera de desarrollo de equipos de Bruce Tuckman** (1965) y su revisión con **Mary Ann Jensen** (1977), alineada con la **Guía del PMBOK® 6.ª Edición (Sección 9.4 — Desarrollar el Equipo)** y aplicada a proyectos de Ingeniería de Software.

## Contenido interactivo

- **Fundamentos teóricos**: Los dos planos paralelos del modelo original (*Estructura grupal / interpersonal* y *Actividad de tarea*).
- **Curva interactiva multicapa**: Evolución de rendimiento, moral, conflicto y dependencia del líder a lo largo de *Formación, Turbulencia, Normalización, Desempeño y Disolución*.
- **Simulador de no linealidad**: Inyección de eventos reales (*scope creep*, ingreso de un dev senior, salida del Tech Lead, equipos veteranos) para observar retrocesos y atajos.
- **Liderazgo situacional (Hersey–Blanchard)** y matriz comparativa maestra.
- **Caso práctico de software (*Squad Nova*)**: Diálogos estilo Slack desde el Sprint 0 al cierre.
- **Autodiagnóstico de equipo (8 ítems)** con plan de acción inmediato.
- **Quiz situacional tipo examen PMBOK / PMP** (5 escenarios con retroalimentación).
- **Pensamiento crítico**: Comparación con el *Equilibrio Puntuado* de Connie Gersick (1988), tarjeta de repaso **F-T-N-D-D** y referencias APA 7.

## Despliegue en Vercel

Este repositorio contiene un sitio estático puro (`index.html`), sin paso de compilación ni dependencias externas:

1. Sube este repositorio a GitHub.
2. En [Vercel](https://vercel.com/new), importa el repositorio.
3. Mantén **Framework Preset: Other** (sin comando de build ni carpeta de salida) y haz clic en **Deploy**.
